# 本地预览持续加载修复

基线：`cursor/fix-condition-amounts-8152` / `d5dbca486b62bf04314aafe7bce51fae9d187eae`。

## 已确认的问题

1. Next.js 的召回、重排及生图网络调用没有截止时间，上游不返回时，接口无法结束。
2. 文案请求原本只限制等待响应头；获取正文发生在计时器清除之后，正文卡住仍会一直等待。
3. 页面聊天及确认、重新筛选请求没有客户端时限，`finally` 必须等请求结束才能解除按钮禁用。
4. 确认商品、重新筛选缺少 `catch`，状态查询和后台同步也有未处理的 Promise 拒绝。
5. 多个候选商品串行检索会累积等待；对话结果没有立即同步至素材页所用的 `guideTurn` 状态。
6. 原版本存在接口返回联合类型、记忆字段和隐式参数类型错误，影响生产构建。

这些是代码和故障模拟确认的缺陷。用户电脑的具体环境变量、网络日志未提供，因此不能据此断定唯一触发原因。

## 修复行为

| 阶段 | 时限 | 到期处理 |
| --- | --- | --- |
| 需求解析 | 12 秒 | 中止请求，沿用现有本地解析 |
| 召回及重排 | 合计 12 秒 | 使用现有本地资料检索；同轮全部候选共用时限 |
| 文案生成 | 45 秒 | 覆盖响应头及完整正文，失败沿用现有事实模板 |
| 生图 | 合计 90 秒 | 覆盖提交、正文及异步轮询，提示结果和费用需核对 |
| 页面状态/后台同步 | 15 秒 | 结束等待并处理异常；本地会话仍保留 |
| 普通页面操作 | 60 秒 | 结束加载，显示错误 |
| 页面素材操作 | 150 秒 | 为文案加生图留出时间，结束等待，提示核对结果 |

所有上述超时均不会自动重新提交模型或生图请求。异步生图仅保留原有 GET 状态轮询；超时后也不再继续轮询。中止本地 HTTP 等待不等于厂商已取消任务，不宣称免费或未扣费。

## 验证与启动

见 README 的启动及检查命令。`tests/request-deadlines.mjs` 模拟请求不返回、正文不返回、重排不返回，验证取消信号、降级和不自动重试，不连接真实模型服务。

调试时先确认打开的是当前 Next.js 入口 http://localhost:3000，而非旧版 4173 页面。切换版本后停止旧进程，再启动新版本。

## 生图配置与接口修复

- 旧版服务现在与 Next.js 使用同一套环境文件加载优先级。`.env.local` 可以覆盖 `.env`；进程环境变量优先级最高。
- 新增 `npm run doctor`，只输出是否配置、字段来源、覆盖文件、接口路径和模型名，不输出 API Key、不调用模型。生产预览使用 `npm run doctor -- --production`。
- 生图优先使用 IMAGE_API_KEY；留空且配置的是官方 HTTPS 阿里云域名时，可以复用 DASHSCOPE_API_KEY，不向第三方地址转发该共享密钥。
- OpenAI Images 协议使用 `1024x1024`；原生 DashScope 协议使用星号尺寸。Qwen 3.0/Pro 默认 1024、单张、关闭额外思考以减少等待；旧 Qwen Image/Plus/Max 原生协议使用其支持的 1328 预设尺寸。
- 保留显式填写的 3.0 原生异步接口路径，使用 messages 请求结构与异步请求头，轮询不会重新提交生成任务。
- 缺配置、开关关闭和格式错误给出具体字段；服务端返回请求编号时保留脱敏编号，便于定位失败。
- 活动校验使用上海时区当天日期，避免一直按 2026-10-06 判断。

接口依据：[Qwen 3.0 图像生成与编辑](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)、[旧版千问文生图](https://help.aliyun.com/zh/model-studio/qwen-image-api)。本地配置检查不能证明账户权限、余额或厂商服务健康。

## 生图 HTTP 400：url error

该错误说明请求已经发出。按阿里云错误码文档，模型与接口不匹配是可能原因；仅凭这句提示不能认定密钥或余额错误。当前应用直接使用 HTTP，不依赖 DashScope SDK。

- 官方阿里云主机下，误填 `qwen3.7-plus`、`qwen-plus`、Qwen-VL 或嵌入模型等明显非生图模型时，调用前阻止并说明 `IMAGE_MODEL` 配置错误。
- 服务端返回 `url error` 时，页面显示实际模型名、接口路径和配置检查方向，同时保留请求编号；不会自动切换模型或接口重试。
- Qwen Image 3.0 的 `/compatible-mode/v1/images/generations` 是官方支持的路径，不应仅凭错误文案认定这条路径错误。可按控制台示例核对模型名，或显式配置官方 DashScope 同步完整地址（程序已支持对应请求体）。
- 排查时提供 `npm run doctor` 的 `image.model`、`endpoint`、`protocol` 和本次请求编号即可，不需要提供 API 密钥。
